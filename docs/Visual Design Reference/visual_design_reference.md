# Visual Design Reference

This document records visual preferences to guide exploration of LiftMetrics. It is inspiration, not a final visual system, layout decision, or component specification. Keep the product mobile-first and let layouts adapt to the screen.

## Preferred visual direction

- **Overall feel:** warm, calm, editorial, and quietly confident; polished but still practical for everyday use.
- **Palette:** primarily white and warm off-white surfaces, with terracotta or soft orange as the main accent. Use dark ink for strong text and muted gray-blue tones for secondary text and subtle details.
- **Typography:** an editorial character is appealing, especially in prominent headings. Keep body text, labels, and controls highly legible and easy to use.
- **Surfaces:** favor restrained contrast, subtle borders, and soft neutral backgrounds. The page should feel open rather than visually busy.

## Exploratory color cues

These approximate colors capture the preference and can change during design work:

- Warm white: `#FBF8F3`
- Terracotta orange: `#C66E4E`
- Dark ink: `#1F2A35`
- Muted blue-gray: `#667782`

## How to use this reference

Use the mostly-white, orange-accented editorial style from the mobile concept the user preferred as a starting point for future mockups. Do not treat that concept's layout, photography, typography details, spacing, or components as settled. Explore alternatives that preserve the preferred mood and palette, and refine choices with the user as the interface takes shape.
